## 📚 About This Repository

This is part of the **Multi-Language Interactive Learning** series. Master TypeScript with:

- ✅ Interactive coding environment
- ✅ Type-safe programming practices
- ✅ Modern ES6+ features
- ✅ Real-world projects
- ✅ Full-stack development

## 🎯 Curriculum

1. **Introduction** - What is TypeScript?
2. **Basic Types** - Strings, numbers, booleans
3. **Advanced Types** - Interfaces, types, generics
4. **Functions** - Arrow functions, overloads
5. **Classes & OOP** - Inheritance, abstract classes
6. **Modules** - Imports, exports, namespaces
7. **Async Programming** - Promises, async/await
8. **Decorators** - Class and method decorators
9. **Configuration** - tsconfig.json, webpack
10. **Full-Stack Project** - Build a complete app
