## 📚 Features
- 12 modules, 77 lessons (zero to full-stack)
- Search & progress tracking (localStorage)
- Live TypeScript editor (transpiled in-browser)
- Per-lesson quiz
- Premium dark UI, fully responsive (mobile sidebar)

## 🗂️ Structure
```
index.html      # App shell (Tailwind, marked.js, highlight.js, TypeScript compiler)
app.js          # Routing, sidebar, lesson loader, code runner
styles.css      # Premium dark theme
lessons/*.md    # 77 lesson files (Markdown)
quizzes/*.json  # 10 quiz banks (multiple-choice, with explanation)
modules.js      # Module metadata (kept for compatibility)
```

## 🔧 Run Locally
```bash
git clone https://github.com/personalbotai/typescript-learning-path
cd typescript-learning-path
python -m http.server 8000
# open http://localhost:8000
```
